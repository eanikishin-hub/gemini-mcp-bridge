# gemini-mcp-bridge — Claude работает с Gemini через вашу подписку

Мост (MCP-коннектор), через который Claude сам работает с [Gemini](https://gemini.google.com) под вашим
входом в Google: рисует картинки Nano Banana, дорабатывает ваши картинки, находит и читает ваши прошлые чаты
в Gemini, продолжает их, выбирает модель, запускает Deep Research. Всё идёт из вашей подписки Gemini,
а не за деньги за каждую картинку.

**Как подключить:** отдайте своему Claude файл [ИНСТРУКЦИЯ-ДЛЯ-CLAUDE.md](ИНСТРУКЦИЯ-ДЛЯ-CLAUDE.md) —
он поставит мост на ваш сервер сам. От вас — один раз войти в Google и добавить коннектор в claude.ai.
Там же — как подключить NotebookLM.

## Что умеет

- Картинки Nano Banana (обычная и Pro) в нужных пропорциях (1:1, 3:4, 9:16, 16:9 …), в полном размере,
  значок Gemini в углу убирается.
- Доработка своей картинки («сделай фон светлее») и продолжение того же разговора.
- Чаты: новый, продолжить старый (в том числе начатый в браузере), список прошлых чатов, чтение чата целиком.
- Выбор модели, Gems, Deep Research, остаток лимитов.
- Готовые файлы приходят ссылками (на сервере хранятся 14 дней).

## Честно о рисках

- Это **неофициальный** путь: программа повторяет действия браузера с вашим входом. Правила Google это
  запрещают, гарантий нет. Чаще всего бывает так: вход «протухает» и его надо обновить; при частых запросах
  Google подсовывает слабую модель. Блокировок аккаунта за такой мост в жалобах пользователей мы не нашли,
  но это не значит, что их не бывает.
- Куки входа — это ключ ко всему вашему Google-аккаунту. Они хранятся только на вашем сервере (папка, доступная
  только мосту) и уходят только в Google — это можно проверить по коду.
- Чтобы не выглядеть роботом, у моста есть предохранитель: одна картинка за раз, пауза 20–40 секунд между
  картинками, не больше 50 картинок в сутки, а при сообщении «лимит исчерпан» — пауза на 6 часов.
  Числа меняются в `/etc/most-gemini.env`.
- Сервер должен быть **не в России** — иначе Google не пустит в Gemini.

## Из чего сделано

- Библиотека [gemini-webapi](https://github.com/HanaokaYuzu/Gemini-API) (HanaokaYuzu), версия закреплена —
  чужой код сам не обновляется.
- Удаление значка Gemini — из [AndyShaman/gemini-webapi-mcp](https://github.com/AndyShaman/gemini-webapi-mcp).
- Лицензия AGPL-3.0, как у обоих.

## Для того, кто ставит руками

```bash
git clone https://github.com/eanikishin-hub/gemini-mcp-bridge && cd gemini-mcp-bridge
sudo bash install/install.sh gemini.ваш-домен.ru      # или без адреса — только для Claude Code на этом сервере
sudo gemini-vhod --json cookies.json                   # вход в Google из выгрузки кук (или --paste)
```

Пароль страницы подключения и адрес коннектора — в `/root/most-gemini-dostup.txt`.
Проверить, жив ли мост: `curl -s "http://127.0.0.1:8150/health?check=1"`.
